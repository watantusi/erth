# 🚜 星際除草王 Planet Mower

一款 3D 闖關除草遊戲：駕駛除草機在 6 顆小星球表面割草，達到目標比例就過關。
支援 **手機、平板、電腦** 瀏覽器（three.js，免安裝、免建置）。

## 怎麼玩
- 用瀏覽器開啟 `index.html`（需透過 http 伺服器，例如 `npx serve planet-mower` 或 `python3 -m http.server`，或部署到 GitHub Pages）。
- **電腦**：W/S 或 ↑/↓ 前進後退，A/D 或 ←/→ 轉向，Shift/空白鍵 加速，P/Esc 暫停，M 靜音。
- **手機/平板**：左半螢幕拖曳虛擬搖桿，右下「加速」鈕。
- 3 條命；剩餘時間越多星星越多（最多 3 顆），進度會自動存檔。

## 星球
| # | 星球 | 特色 |
|---|---|---|
| 1 | 翠綠星 | 新手草坪 |
| 2 | 沙丘星 | 仙人掌：撞到會暈眩 |
| 3 | 冰晶星 | 地面很滑 |
| 4 | 熔岩星 | 熔岩池會燒傷扣命 |
| 5 | 紫晶星 | 播種蟲會把草種回去，部分草會再長 |
| 6 | 暗影星 | 終章：夜光草＋所有危險 |

道具：🔶 超寬刀片、⏱️ 加時間、⚡ 加速能量。草剩不多時會出現黃色箭頭指引。

## 程式結構
| 檔案 | 內容 |
|---|---|
| `js/main.js` | 遊戲迴圈、球面移動、草地（InstancedMesh + shader）、碰撞、相機、粒子 |
| `js/world.js` | 關卡資料、星球外觀、星空、大氣光暈、遠方天體 |
| `js/models.js` | 程序化低多邊形模型（除草機、播種蟲、岩石、仙人掌、晶體、道具） |
| `js/ui.js`, `css/style.css` | 畫面、HUD、觸控搖桿 |
| `js/audio.js` | WebAudio 合成音效與背景音樂 |
| `SPEC.md` | 開發規格 |
