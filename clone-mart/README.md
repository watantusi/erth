# 分身便利店 CLONE MART RUSH

一款用 Three.js 做的 3D 便利商店「出餐大作戰」：客人在上方丟出點單，你和 AI 分身要在時間內把東西做好、送到黃色的「出餐」台。手機、平板、電腦的瀏覽器都能玩，不用安裝。

開啟 `clone-mart/index.html` 就能開始（需要網路載入 3D 引擎）。進度（最高分、星星、看過的教學提示、上次帶的分身）自動存在瀏覽器裡。

## 操作

| | 手機／平板 | 電腦 |
| --- | --- | --- |
| 走路 | 左手在畫面上拖曳（虛擬搖桿），或點一下台子直接走過去 | WASD／方向鍵，或滑鼠點擊 |
| 拿起／放下／組合／出餐 | 右下角 ✋ 大按鈕 | 空白鍵或 J |
| 長按動作（切水果、噴滅火器、拖地、修理） | 🔪 按鈕按住不放 | E 或 K 按住 |
| 換人操作 | 🔄 | Q 或 Tab（Shift+Tab 反向） |
| 看全店／全螢幕／暫停 | 🔭／⛶／❚❚ | V／F／Esc 或 P |

按鈕上的字會跟著你面前的台子改變（拿起、放下、夾起來、組合、出餐、丟掉…），黃色光圈標出你現在會操作的台子。

### 👥 雙人同樂（同一台裝置）

開店前在準備畫面打開「👥 雙人同樂」（電腦一定有；手機／平板要接兩支手把才會出現）。2P 會接手隊伍裡的一個分身（沒帶分身就多一位 2P 夥伴），分數共用，結算單會列出 1P／2P 各送了幾份。

| | 1P | 2P |
| --- | --- | --- |
| 走路 | WASD | 方向鍵 |
| 拿起／放下 | 空白鍵或 J | Enter、右 Shift 或 Numpad0 |
| 長按動作 | E 或 K | / 或 Numpad1 |
| 換人（不會換到對方的角色） | Q 或 Tab | . 或 Numpad2 |
| 手把 | 第 1 支 | 第 2 支 |

鏡頭會對準兩人中間，兩人離越遠拉得越遠（最多到看全店）；光圈和頭上標籤：1P 黃色、2P 藍色。

## 玩法

- **點單**：上方一排票卡就是客人的點單，寫著要做什麼和步驟；底下的時間條變紅、票卡開始晃，就快逾時了。
- **出餐**：做好的東西拿到收銀台上黃色的「出餐」台，會自動交給最急的那張單。
- **分數**：每份餐有底分；越快送到小費越多。照順序先送**最舊的那張單**會累積連擊（最多 ×3 小費）。逾時沒送到會扣分。
- **燒焦和起火**：微波爐、烤台、湯鍋做好後要趕快拿，放太久會變成 💀 失敗品；失敗品還留在微波爐／烤台上就會起火，火會延燒到旁邊的台子。到西牆拿 🧯 滅火器，對著火長按動作。
- **水漬**：踩到會變慢，空手站在旁邊長按動作拖乾。
- **跳電**：故障 ⚡ 的機器不會動，空手站在旁邊長按動作修好。
- **分身**：其他分身會自己找自己負責的單來做。隨時可以換人操作，被你換掉的人會接著自己工作；老闆沒人操作時會站著不動。

## 關卡

每關都有一個「今日特色」，在關卡卡片、開店前的準備畫面和開店倒數時都會顯示。前一關拿到 ★ 才會開下一關。

| 關卡 | 菜單 | 今日特色 | 分身名額 | ★／★★／★★★ |
| --- | --- | --- | --- | --- |
| 1 開店第一天 | 飲料、零食、咖啡 | 📘 **新手教學**：前三張單固定是飲料 → 零食 → 咖啡，一次只來一張、時間很寬，教學時計時暫停；做完才正式開始（拿到 ★ 後重玩會跳過） | 1 | 260／400／550 |
| 2 早餐尖峰 | 咖啡、飯糰、泡麵、飲料 | 🧾 **團購單**：有些單票角寫 ×2，要送 2 份才完成，分數加倍 | 1 | 450／730／1010 |
| 3 午餐大爆滿 | 便當、大亨堡、咖啡、飲料 | 🍱 **午餐尖峰**：中段有 45 秒客人一口氣湧進來（畫面大字預告＋右上倒數） | 2 | 660／880／1110 |
| 4 下雨的傍晚 | 關東煮、大亨堡、咖啡、泡麵 | ☔ **雨傘水漬**：每隔一陣子一群客人帶著濕雨傘進來，一次濕好幾攤（會先預告） | 2 | 870／1120／1380 |
| 5 深夜加班 | 水果杯、關東煮、便當、熱狗套餐、咖啡 | 👑 **VIP**：戴金帽的客人，金色票卡，分數兩倍但時間只有六成 | 3 | 1650／1950／2270 |
| 6 颱風夜大混亂 | 七種全上 | ⚡ **颱風跳電**：每次跳電一口氣壞兩台機器（會先預告） | 3 | 310／740／1180 |
| 24H 無限營業 | 全部 | 🔥 VIP、團購單、每 150 秒一次宵夜尖峰全都來，點單越來越快、時間越來越短；錯過 5 張單就打烊 | 5 | 3600／4500／5300 |

星星門檻用模擬校準：只靠 AI 分身（老闆站著不動）拿不到 ★，要自己下場一起做才行。結算收據會列出 VIP、團購、尖峰的成績，並給一句下次可以改進的建議。

## 五個 AI 分身

總星星數越多，解鎖越多種分身；每關能帶的人數有限，在準備畫面挑選（會自動推薦適合這關菜單的人）。

| 分身 | 解鎖 | 會做的事 |
| --- | --- | --- |
| ☕ 咖啡分身 | 一開始就有 | 熱咖啡、泡麵 |
| 🍱 熱食分身 | ★2 | 熱便當、關東煮 |
| 🌭 烤台分身 | ★4 | 大亨堡、熱狗套餐 |
| 🔪 備料分身 | ★7 | 水果杯、飯糰、飲料、零食 |
| 🧯 清潔分身 | ★10 | 拖地、丟失敗品、滅火、修理跳電的機器 |

分身走得比你慢、動作也慢一點；最好的打法是自己去做分身不會做的菜，或在某條線塞車時換人過去幫忙。

## 教學提示

每種餐點、每個新機制（燒焦、起火、水漬、跳電、團購、VIP、尖峰、連擊、換人…）第一次出現時，畫面下方會跳出一次說明，看過就不會再出現；已經過時的提示（例如那張單已經送掉了）會自動跳過，下次遇到再說。
