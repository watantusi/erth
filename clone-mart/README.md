# 分身便利店 CLONE MART 24H

一款用 Three.js 做的 3D 便利商店經營遊戲，手機、平板、電腦的瀏覽器都能玩，不用安裝。

開啟 `clone-mart/index.html` 就能開始（需要網路載入 3D 引擎）。

## 玩法

- **移動**：手機／平板在畫面上拖曳（虛擬搖桿），或點一下地板、貨架直接走過去；電腦用 WASD／方向鍵或滑鼠點擊。雙指或滾輪縮放。
- **視角**：直拿手機／平板會自動轉成直式視角，看得到更多店面；右上角 🔭 一鍵看全店（鍵盤 V），⛶ 全螢幕（鍵盤 F，支援的瀏覽器才會出現）。畫面外有客人排隊、貨架缺貨或小偷時，邊緣會出現箭頭，點一下就會走過去。
- **收銀**：站進藍色「收銀」格子，排隊的客人會自動結帳。
- **咖啡**：有些客人要咖啡，站到「咖啡」格子沖咖啡備用。
- **補貨**：到倉庫「拿貨」格子拿箱子，走到不滿的貨架前就會補滿（會扣進貨成本）。
- **清潔**：走到垃圾或打翻的飲料上站一下就能清掉，髒亂會讓客人沒耐心、評價下降。
- **抓小偷**：第 2 天起會有小偷（🕶️），在他們走出門前追上去就能攔下。

每天 07:00 開店、23:00 打烊（約 3 分鐘），打烊後付分身薪水和店租。現金變負數，或打烊時評價低於 0.5 顆星，店就會倒閉。進度會自動存在瀏覽器裡。

## 五個 AI 分身

| 分身 | 工作 |
| --- | --- |
| 🧾 收銀分身 | 守在收銀台自動結帳 |
| 📦 補貨分身 | 貨架快空時自己去倉庫搬貨上架 |
| 🧹 清潔分身 | 找到垃圾就去清乾淨 |
| ☕ 咖啡分身 | 持續沖咖啡，收銀台沒人時幫忙結帳 |
| 🛡️ 保全分身 | 門口迎賓讓客人更有耐心，並追捕小偷 |

每個分身都能升到 LV3，動作更快。

## 每日目標、活動與店鋪升級

- **今日目標**：每天 3 個目標（量：結帳人數／營收；技巧：咖啡杯數／抓小偷／服務 VIP；品質：零氣走客人／沒被偷／打烊評價），會隨天數變難。每完成一項拿獎金和評價，三項全達成再加一份獎金。目標欄在畫面右上方，手機上平常收成一行，點一下可以展開。
- **尖峰時段**：11:30–13:00 午餐尖峰（便當、泡麵大賣）、17:30–19:15 下班尖峰（飲料、零食大賣），客人會一口氣湧進來。
- **VIP 👑**：第 3 天起出現，戴金帽，付 1.5 倍的錢但更沒耐心；氣走 VIP 評價掉得特別多。
- **特別日子**：第 4 天起有時會遇到 🏷️ 促銷日、☔ 雨天、💰 發薪日、🥵 熱浪。
- **店鋪升級**：在「分身」面板最下方，可以加大貨架、換高速咖啡機、快速收銀機、招牌燈箱。店租會越漲越快，後期只靠 LV1 分身撐不住，記得升級。
