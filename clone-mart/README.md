# 分身便利店 CLONE MART RUSH

一款用 Three.js 做的 3D 便利商店「出餐大作戰」：客人在上方丟出點單，你和 AI 分身要在時間內把東西做好、送到黃色的「出餐」台。手機、平板、電腦的瀏覽器都能玩，不用安裝。

開啟 `clone-mart/index.html` 就能開始（需要網路載入 3D 引擎）。進度（最高分、星星、看過的教學提示、上次帶的分身）自動存在瀏覽器裡。

## 操作

| | 手機／平板 | 電腦 |
| --- | --- | --- |
| 走路 | 左手在畫面上拖曳（虛擬搖桿），或點一下台子直接走過去 | WASD／方向鍵，或滑鼠點擊 |
| 拿起／放下／組合／出餐／裝外送袋 | 右下角 ✋ 大按鈕 | 空白鍵或 J |
| 長按動作（切水果、搖珍奶、翻玉米、噴滅火器、拖地、修理） | 🔪 按鈕按住不放（站著不動時切水果、搖珍奶、翻玉米會自動做） | E 或 K 按住 |
| 換人操作 | 🔄 | Q 或 Tab（Shift+Tab 反向） |
| 看全店／全螢幕／暫停 | 🔭／⛶／❚❚ | V／F／Esc 或 P |

按鈕上的字會跟著你面前的台子改變（拿起、放下、夾起來、組合、出餐、丟掉…），黃色光圈標出你現在會操作的台子。

## 玩法

- **點單**：上方一排票卡就是客人的點單，寫著要做什麼和步驟；底下的時間條變紅、票卡開始晃，就快逾時了。
- **出餐**：做好的東西拿到收銀台上黃色的「出餐」台，會自動交給最急的那張單。
- **分數**：每份餐有底分；越快送到小費越多。照順序先送**最舊的那張單**會累積連擊（最多 ×3 小費）。逾時沒送到會扣分。
- **燒焦和起火**：微波爐、烤台、湯鍋做好後要趕快拿，放太久會變成 💀 失敗品；失敗品還留在微波爐／烤台上就會起火，火會延燒到旁邊的台子。到西牆拿 🧯 滅火器，對著火長按動作。
- **水漬**：踩到會變慢，空手站在旁邊長按動作拖乾。
- **跳電**：故障 ⚡ 的機器不會動，空手站在旁邊長按動作修好。
- **外送單（第二章起）**：綠色票卡、角上寫 🛵外送（⚡急件），一張要 2～3 樣東西。每做好一樣，拿到門口右邊的 👜 **打包台** 按 ✋ 裝袋，票卡上會打勾，袋子裡看得到裝了什麼；裝齊會自動封袋。封好的袋子拿去門邊的 🛵 **外送取餐架**：外送員到了就直接交給他，還沒到就先放在架上，他一到就會拿走。外送員會照票卡上的秒數騎過來，到了站在門口等，頭上的時間條跑完就生氣離開（扣分）。外送袋不能拿去出餐台。
- **雙拼單（第三章）**：粉紅色票卡、角上寫 🎏雙拼，一張要兩樣不同的東西，各自送到出餐台，兩樣都到才算完成，分數加成。
- **分身**：其他分身會自己找自己負責的單來做（外送單和雙拼單也會分頭做自己會的那一樣，做好自己拿去裝袋）。隨時可以換人操作，被你換掉的人會接著自己工作；老闆沒人操作時會站著不動。

| 關卡 | 菜單 | 今日特色 | 分身名額 | ★／★★／★★★ |
| --- | --- | --- | --- | --- |
| 24H 無限營業（第 1-6 關拿到 ★ 開放） | 第一章全部 | 🔥 VIP、團購單、每 150 秒一次宵夜尖峰全都來，點單越來越快、時間越來越短；錯過 5 張單就打烊 | 5 | 3600／4500／5300 |

星星門檻用模擬校準：只靠 AI 分身（老闆站著不動）拿不到 ★，要自己下場一起做才行（★ ≈ AI + 15%、★★ ≈ +42%、★★★ ≈ +70% 的「老闆＋分身」差距；AI 偶爾手氣好的那幾場也拿不到 ★）。結算收據會列出 VIP、團購、尖峰、外送、雙拼的成績和包錯扣分，並給一句下次可以改進的建議。

## 店裡的新站點

- **外送專區**（門口右邊）：打包台（兩個袋位，可以同時裝兩張外送單）和外送取餐架；外送員從門口進來站在取餐架旁，第二位以後在門外人行道等。
- **珍奶吧**（倉庫西牆，從賣場右上進倉庫）：紅茶桶、珍珠鍋、搖杯。
- **烤玉米架＋玉米箱**（冷藏櫃右邊、倉庫牆前）：炭火，不怕停電。
- **刈包攤**（西北角）：蒸籠、滷肉鍋、花生粉。

這些站點每一關都在店裡，只有用到的關卡才會有那些單。

## 五個 AI 分身

總星星數越多，解鎖越多種分身；每關能帶的人數有限，在準備畫面挑選（會自動推薦適合這關菜單的人）。

| 分身 | 解鎖 | 會做的事 |
| --- | --- | --- |
| ☕ 咖啡分身 | 一開始就有 | 熱咖啡、泡麵、珍珠奶茶 |
| 🍱 熱食分身 | ★2 | 熱便當、關東煮、刈包 |
| 🌭 烤台分身 | ★4 | 大亨堡、熱狗套餐、烤玉米（會自己翻面） |
| 🔪 備料分身 | ★7 | 水果杯、飯糰、飲料、零食；把封好的外送袋交給外送員 |
| 🧯 清潔分身 | ★10 | 拖地、丟失敗品、滅火、修理跳電的機器 |

外送單和雙拼單裡的每一樣，會由會做那一樣的分身各自做好、自己拿去裝袋；只有備料分身會把封好的袋子交給外送員，沒帶它的話送袋子就是你的工作。分身走得比你慢、動作也慢一點；最好的打法是自己去做分身不會做的菜，或在某條線塞車時換人過去幫忙。

## 教學提示

每種餐點、每個新機制（燒焦、起火、水漬、跳電、團購、VIP、尖峰、連擊、換人、外送、急件、封袋、外送員到了、包錯、翻玉米、搖珍奶、停電…）第一次出現時，畫面下方會跳出一次說明，看過就不會再出現；已經過時的提示（例如那張單已經送掉了）會自動跳過，下次遇到再說。
