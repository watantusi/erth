# 地球小旅人 Tiny Earth Wanderer

一款原創的 3D 小星球漫遊網頁遊戲，手機、平板、電腦的瀏覽器都能玩，不用安裝。

小小的地球正在褪色。你扮演一位小旅人，走遍六個生態區（青青草原、翠綠森林、金色沙漠、冰雪極地、火山高地、蔚藍海洋），
收集 12 顆「知識晶石」認識地球科學小知識，在 8 塊荒地種下幼苗，並幫 6 位居民完成請託，讓星球重新繽紛起來。

- **平台挑戰**：每個生態區都有一座跳台路線（乾草堆瞭望台、樹樁螺旋梯、砂岩方山、冰柱之字路、玄武岩六角柱、海蝕柱踏石路），頂端放著一顆晶石，還有會把你彈高的蘑菇。
- **解鎖指南針**：一開始沒有箭頭，只知道自己在哪個生態區。向機器人「嗶嗶」打招呼可以拿到 20 秒訊號；完成居民任務得到地圖碎片，指南針會逐步升級成常駐箭頭、顯示距離，最後解鎖雷達小地圖。
- **居民任務**：咩咩村長找小雞、松鼠栗栗收集松果、駱駝阿沙要在冰融化前送到的冰塊、企鵝媽媽找寶寶、岩岩博士的限時火山量測、燈塔海龜的發光海星。
- **知識測驗**：每張知識卡後有一題三選一，答對得 ⭐；答錯可以在「📖 圖鑑」重答。
- **收集與裝扮**：6 頂帽子、6 色圍巾、4 種腳印特效，靠 ⭐、地圖碎片、6 顆藏在難到達處的「金色橡實」、計時挑戰獎牌和通關解鎖；「🎒 衣櫥」會切到角色正面特寫。
- **日夜循環**：一天 8 分鐘，夜晚有星空、月亮、窗戶燈光、螢火蟲、極光和流星；有一顆橡實只在極光下出現。設定裡可以關閉。
- **計時挑戰**：通關後解鎖，8 顆金色時光晶石隨機出現，金 < 78 秒、銀 < 115 秒、銅 < 230 秒。
- **選擇角色**：開始新旅程時從 5 位旅人裡挑一位（小旅人、狐狸探險家、太空小子、熊熊、雲朵仙子），之後可以在衣櫥的「角色」分頁更換。
- **多樣地形**：高山、河流與瀑布、湖泊、峽谷（看得到沉積岩層）、冰河、梯田、海蝕拱門、三角洲，每種地形都有一塊知識牌和一題測驗，收進圖鑑的「地形」分頁。
- **移動速度**：設定裡可以選慢／標準／快。
- 路上還藏著鯨魚、恐龍化石、瓶中信等小彩蛋。

## 怎麼玩

| | 手機 / 平板 | 電腦 |
|---|---|---|
| 移動 | 左半邊拖曳（浮動搖桿），推到底撐住一下會開始跑 | WASD / 方向鍵，Shift 跑步 |
| 跳躍 | 右下「跳」鈕 | 空白鍵 |
| 轉視角 | 右半邊滑動，雙指縮放 | 拖曳滑鼠、Q / E，滾輪縮放 |
| 對話 | 靠近居民時出現的 💬 鈕 | F 或 Enter |
| 表情 | 😊 按鈕 | 1–6 |
| 衣櫥 / 圖鑑 | 🎒 / 📖 按鈕 | B / J |

也支援遊戲手把（左搖桿移動、右搖桿視角、A 跳、RB 跑）。進度會自動存在瀏覽器裡，可以「繼續旅程」。

## 執行

純靜態網頁，不需要建置，也不連外部網路（three.js 已放在 `lib/`）：

```bash
cd game
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

要用手機玩，可以把 `game/` 資料夾放到任何靜態網站空間（例如 GitHub Pages）。

## 技術

- Three.js 0.160（WebGL），全部場景都是程式產生的低多邊形幾何，沒有模型或貼圖檔，整包約 1 MB
- 球面重力、沿球面平行移動的第三人稱鏡頭，走過南北極也不會翻轉
- Web Audio 即時合成的音效與環境音樂
- 遊玩時約 80 個 draw call、無即時陰影，手機也能順跑；設定裡可切換畫質

## 開發分工

這款遊戲由一位整合者和五個 AI 分身並行開發，模組合約寫在 [`ARCHITECTURE.md`](ARCHITECTURE.md)：

| 分身 | 負責 | 檔案 |
|---|---|---|
| 整合者 | 架構、主迴圈、存檔、整合測試 | `index.html`, `style.css`, `js/main.js`, `js/config.js`, `js/utils.js` |
| 1 世界美術 | 星球地形、生態區、平台挑戰、日夜循環、彩蛋 | `js/world.js` |
| 2 角色與物理 | 角色與居民造型、動畫、球面與平台物理 | `js/player.js`, `js/characters.js` |
| 3 操控與鏡頭 | 觸控 / 鍵盤 / 手把、跟隨與特寫鏡頭、雷達、計時挑戰 | `js/input.js`, `js/cameraRig.js`, `js/radar.js`, `js/timetrial.js`, `css/controls.css` |
| 4 玩法與內容 | 晶石、種樹、導航等級、居民任務、知識卡與測驗、裝扮解鎖 | `js/gameplay.js`, `js/quests.js`, `js/content.js`, `js/cosmetics.js` |
| 5 介面音效特效 | HUD、對話框、測驗、衣櫥、圖鑑、計時器、音效音樂、粒子 | `js/ui.js`, `js/audio.js`, `js/effects.js`, `css/ui.css` |
