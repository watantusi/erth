# 地球小旅人 Tiny Earth Wanderer

一款原創的 3D 小星球漫遊網頁遊戲，手機、平板、電腦的瀏覽器都能玩，不用安裝。

小小的地球正在褪色。你扮演一位小旅人，走遍六個生態區（青青草原、翠綠森林、金色沙漠、冰雪極地、火山高地、蔚藍海洋），
收集 12 顆「知識晶石」認識地球科學小知識，並在 8 塊荒地種下幼苗，讓星球重新繽紛起來。
路上會遇到會回應表情的小機器人「嗶嗶」，還藏著幾個小彩蛋等你發現。

## 怎麼玩

| | 手機 / 平板 | 電腦 |
|---|---|---|
| 移動 | 左半邊拖曳（浮動搖桿），推到底會跑 | WASD / 方向鍵，Shift 跑步 |
| 跳躍 | 右下「跳」鈕 | 空白鍵 |
| 轉視角 | 右半邊滑動，雙指縮放 | 拖曳滑鼠、Q / E，滾輪縮放 |
| 表情 | 😊 按鈕 | 1–6 |

也支援遊戲手把（左搖桿移動、右搖桿視角、A 跳、RB 跑）。進度會自動存在瀏覽器裡，可以「繼續旅程」。

## 執行

純靜態網頁，不需要建置，也不連外部網路（three.js 已放在 `lib/`）：

```bash
cd game
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

要用手機玩，可以把 `game/` 資料夾放到任何靜態網站空間（例如 GitHub Pages）。

## 技術

- Three.js 0.160（WebGL），全部場景都是程式產生的低多邊形幾何，沒有模型或貼圖檔，整包約 0.9 MB
- 球面重力、沿球面平行移動的第三人稱鏡頭，走過南北極也不會翻轉
- Web Audio 即時合成的音效與環境音樂
- 約 50 個 draw call、無即時陰影，手機也能順跑；設定裡可切換畫質

## 開發分工

這款遊戲由一位整合者和五個 AI 分身並行開發，模組合約寫在 [`ARCHITECTURE.md`](ARCHITECTURE.md)：

| 分身 | 負責 | 檔案 |
|---|---|---|
| 整合者 | 架構、主迴圈、存檔、整合測試 | `index.html`, `style.css`, `js/main.js`, `js/config.js`, `js/utils.js` |
| 1 世界美術 | 星球地形、生態區、道具、天空、彩蛋 | `js/world.js` |
| 2 角色與物理 | 角色造型與動畫、球面物理 | `js/player.js` |
| 3 操控與鏡頭 | 觸控 / 鍵盤 / 手把、跟隨鏡頭 | `js/input.js`, `js/cameraRig.js`, `css/controls.css` |
| 4 玩法與內容 | 晶石、種樹、機器人 NPC、知識卡 | `js/gameplay.js`, `js/content.js` |
| 5 介面音效特效 | HUD、彈窗、音效音樂、粒子 | `js/ui.js`, `js/audio.js`, `js/effects.js`, `css/ui.css` |
